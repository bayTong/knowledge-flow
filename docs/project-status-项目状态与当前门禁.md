## 4. 当前边界

`P0C-UX0` 只允许把两项 P0V 真实 UX 摩擦收敛成可实现、可验收的最小交互契约；不允许：

- 修改产品代码、Capture schema、Pilot Store、备份或恢复副本；
- 把“查看历史版本”解释为改写、删除或倒退既有版本；恢复只能被定义为将选定旧正文追加成新的 `N+1` 版本；
- 顺带引入 Capture 删除、可恢复归档状态机、批量管理、可信知识回滚或新的持久化状态；
- 改变四个公共 Capture 操作、管理/备份恢复契约、错误提交状态或现有数据保护声明；
- 接入模型、RAG、GBrain、知识图谱、外部账号或网络服务；
- 未经下一次独立授权就从契约收口直接进入实现。
