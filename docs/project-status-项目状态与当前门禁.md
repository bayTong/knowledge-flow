## 4. 当前边界

`EVIDENCE-0` 与联合契约候选已经版本化，[CUR-MVP-1 实施方案](curation/40-cur-mvp-1-execution-plan-首个可用策展地图纵向切片实施方案.md)现为获批实施计划；[捕获与路由规范](capture/capture-and-routing-spec-捕获与路由规范.md)、[深入策展流程总览](curation/00-deep-curation-workflow-深入策展流程总览.md)、[SOP-10 新建知识库骨架](curation/10-sop-new-kb-bootstrap-新建知识库骨架.md)和[SOP-20 材料深度理解与策展地图](curation/20-sop-deep-curation-map-材料深度理解与策展地图.md)只有 `CUR-MVP-1` 所需子集获准分批实施。[SOP-30](curation/30-sop-trusted-write-批准后写入可信知识.md)仍是 Review Candidate。下一产品门禁 `CUR-MVP-1` 仍必须：

- 明确深入策展的精确来源版本、深度处理范围与单一新隔离 KB 的首个可执行闭环，复用已登记的长篇材料和必要机械夹具；零散笔记与独立多来源材料只保留后置登记，不作为深入路径前置或当前读取范围。只使用精确白名单的隔离副本；不得触碰 Pilot Store、既有 active KB、备份或恢复副本；
- 写清活动材料的默认任务、人工 gold 或核查方法、处理授权和代表性；特定问题与熟悉程度不是用户开始任务前的必填表单，但实际运行采用的任务和解释边界必须记录；
- 冻结首次有用结果时间、整体理解与整理收益、证据定位/支持正确性、人工操作与审核时间、可见缺口、失败样例，以及使用模型时的调用和成本记录；
- 将来源身份、分段、范围和 locator 作为首个地图纵向切片的内部机械检查点；允许为复核风险拆分代码提交，但不得把它包装成独立产品阶段。`CUR-MVP-1` 只有在目标判断、一个新 KB、`raw/` 映射和可核验地图共同可用时完成；随后才进入 `CUR-MVP-2` 的变更准备、批准和受限写入。低摩擦和独立检索设计后置，不用单一字数阈值预先决定永久产品路线；
- 明确“放进某个库”“允许深度处理”“批准写入可信知识”分别授权，地图任务成功不等于可信晋升，也不免除项目对一条真实写入链的阶段验收；
- 明确 Capture 与无目标地图不依赖 Git；绑定目标 KB 的受管地图/决定与 T3 使用 KnowledgeFlow 管理、无 remote 的本地版本库，所有检查点离线完成且不能把技术 commit 冒充业务批准或备份；
- 首轮语义结果只建立实测基线，不预设无依据的命中率或接受率通过阈值；机械身份、分段、范围和 locator 仍为全通过门禁；
- 规定数据隔离、可重复运行、结果清理和停止条件，并明确单次演示不能证明通用准确率。

当前边界不允许：

- `CUR1B/CUR1C` 修改 Capture schema、Pilot Store、备份、恢复副本或当前收件箱；CUR1C 只允许在显式测试/实验根内创建 provisional KB 与 `raw/` 映射，不得接入已有 active KB 或生产路径；
- 把 `CUR1A–CUR1C` 或尚未复核的 `CUR1D-CODE` 独立升级为“产品已完成”，或把临时机械验收外推为策展价值有效；把 C-K/非 C-K 来源忠实度抽查外推为外部事实正确、全文完整或统计准确率；把本地模拟实现误写成真实 `CUR1D` 已运行；在 `CUR1D-RUN` 授权前调用真实 API、读取/发送 `E0-C` 正文或生成真实地图；在精确方案批准与 `CUR-MVP-2` 单独授权前执行任何 `wiki/` 可信写入。旧 SOP-002 始终不得恢复执行；
- 先冻结通用 Task、Ledger、Evidence、Graph 或 RAG 持久化 schema；
- 把模型、embedding、GBrain、图数据库、外部账号或网络设为共同底座或本地检索前置；深入策展/低摩擦整理如需模型仍须另行确认并可完全关闭；
- 把实验性摘要、回答、关系或图谱写入可信知识层；
- 未经后续独立授权，从协议直接进入实现或将单次结果升级为产品有效性声明。

1. 实施者完成检查点后整理证据并提出状态变化；涉及真实数据、产品状态或新阶段升级时由项目所有者确认。
2. 状态变化与支持它的证据应进入同一个独立提交；不能先修改状态、以后再补证据。
3. 只有本文件可以携带 `knowledgeflow-doc-status` 机器锚点；其他现行文档、稳定契约和历史归档不得复制该锚点。
4. 主 PRD 不记录提交、CI 运行号或当前编码批次；设计权威登记不再维护“当前下一步”。
