## 4. 当前边界

`EVIDENCE-0` 只允许规划第一轮可复现价值实验，不允许编码。该门禁必须：

- 选择至少一份中小体量有界材料和一份大体量或多来源材料；只使用可公开、可替代或明确允许的隔离副本，不扩大当前低敏感度 Pilot 声明；
- 写清每份材料要回答的真实用户问题、已知正确结果或人工核查方法，以及为什么它能代表目标使用路径；
- 冻结首次有用结果时间、引用/证据定位正确性、人工操作与审核时间、可见缺口、失败样例，以及使用模型时的调用和成本记录；
- 比较同一 Evidence 底座上的中小体量浏览/检索与可选轻量策展、大体量检索优先问答，不用单一字数阈值预先决定永久产品路线；
- 规定数据隔离、可重复运行、结果清理和停止条件，并明确单次演示不能证明通用准确率。

本门禁不允许：

- 修改产品代码、Capture schema、Pilot Store、备份、恢复副本或当前收件箱；
- 先冻结通用 Task、Ledger、Evidence、Graph 或 RAG 持久化 schema；
- 把模型、embedding、GBrain、图数据库、外部账号或网络设为实验前置；
- 把实验性摘要、回答、关系或图谱写入可信知识层；
- 未经后续独立授权，从协议直接进入实现或将单次结果升级为产品有效性声明。
